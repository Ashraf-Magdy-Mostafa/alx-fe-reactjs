# Recipe Sharing Platform (React + Tailwind)

## Setup
```bash
npm install
npm run dev
```

## Routes
- `/` Home (recipe cards)
- `/recipe/:id` Detail page
- `/add` Add recipe form (front-end validation + responsive UI)

## Notes
This project uses a static `src/data.json` file as mock data.
The add recipe form simulates submission (shows an alert) since the data file is static.
