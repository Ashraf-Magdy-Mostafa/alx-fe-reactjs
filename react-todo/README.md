# react-todo

Task 3: Todo app + tests with Jest + React Testing Library

## Run app
```bash
npm install
npm run dev
```

## Run tests
```bash
npm test
```

## What is included
- `TodoList` with demo todos (static array)
- `AddTodoForm` to add todos
- Toggle by clicking todo item
- Delete each todo
- Tests: initial render, add, toggle, delete
